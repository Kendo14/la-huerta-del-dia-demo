# La Huerta del Día · demo

Versión compilada de un prototipo de pedidos de fruta y verdura para particulares y restaurantes.
Todo funciona en el navegador con datos ficticios: no hay cobros, envíos ni servidor.

Abrir la demo: https://kendo14.github.io/la-huerta-del-dia-demo/

Accesos de demostración en «Mi cuenta»: entrar como particular, como restaurante y modo propietario.
